# 🎓 freeCodeCamp Forum Dashboard

A modern, feature-rich dashboard for browsing and analyzing freeCodeCamp forum activity with real-time updates, filtering, and analytics.

![Forum Dashboard Preview](preview.png)

## ✨ Features

### 📊 Dashboard Overview
- **Real-time Statistics**: Online users, posts today, active topics
- **Category Breakdown**: Visual stats for each forum category
- **Top Contributors**: Most active community members
- **Hot Topics**: Most viewed discussions

### 🔍 Advanced Filtering
- **Smart Search**: Full-text search across topics and categories
- **Category Filtering**: Filter by specific forum categories
- **Multi-view Display**: Switch between table and card views
- **Sort Options**: Sort by activity, replies, views, or date

### 📱 Modern Interface
- **Responsive Design**: Works perfectly on desktop, tablet, and mobile
- **Dark/Light Theme**: Clean, accessible color scheme
- **Interactive Elements**: Hover effects, animations, and visual feedback
- **Loading States**: Smooth transitions and loading indicators

### 📈 Analytics & Insights
- **Category Distribution**: See which topics are most popular
- **Activity Timeline**: Track when discussions are most active
- **User Engagement**: Identify top contributors and helpers
- **Performance Metrics**: Views, replies, and participation rates

## 🚀 How to Use

### 1. Browse Topics
- **Default view** shows latest forum topics
- **Click any topic** to open it on freeCodeCamp forum
- **Switch views** between table (traditional) and cards (modern)

### 2. Search & Filter
- **Type in search bar** to find specific topics
- **Use category filter** to focus on specific areas (JavaScript, Python, etc.)
- **Clear search** with the × button

### 3. Sort Results
- **Choose sorting** from dropdown menu:
  - Latest Activity (default)
  - Most Replies
  - Most Views
  - Newest First
  - Oldest First
- **Click table headers** for instant sorting

### 4. Analyze Data
- **Check sidebar stats** for category distribution
- **View top contributors** to see who's helping most
- **Monitor hot topics** for trending discussions
- **Track forum activity** in real-time

### 5. Navigation
- **Use pagination** to browse through pages
- **Refresh data** with the refresh button
- **Visit full forum** using the link in sidebar
