An interactive educational tool that visualizes sorting and pathfinding algorithms in real-time. Perfect for students, developers, and anyone interested in understanding how algorithms work.

## 🎯 Overview

Algorithm Visualizer transforms complex algorithmic concepts into intuitive visual representations. Watch algorithms come to life with color-coded steps, detailed statistics, and interactive controls.

## ✨ Features

### 📊 **Visualization Types**
- **Sorting Algorithms**: 8+ sorting methods with step-by-step visualization
- **Pathfinding Algorithms**: Coming soon - Dijkstra's, A* Search
- **Searching Algorithms**: Coming soon - Binary Search, Linear Search

### 🎮 **Interactive Controls**
- Real-time speed adjustment (Slow to Fast)
- Array size configuration (5-100 elements)
- Multiple array types (Random, Nearly Sorted, Reverse, Few Unique)
- Play, Pause, Step, and Reset functionality
- Side-by-side algorithm comparison

### 📈 **Detailed Analytics**
- Time and space complexity display
- Step-by-step execution tracking
- Performance metrics (comparisons, swaps, time)
- Memory usage statistics
- Real-time algorithm state visualization

### 🎨 **Visual Features**
- Color-coded element states (comparing, swapping, sorted, pivot, min/max)
- Interactive legend for visual cues
- Responsive design for all devices
- Dark/light theme toggle
- Fullscreen mode for immersive experience

## 🚀 Quick Start

### Prerequisites
- Modern web browser (Chrome, Firefox, Safari, Edge)
- No installation required - runs directly in browser

### How to Use
1. **Open the visualizer** by launching `index.html` in your browser
2. **Select an algorithm** from the Sorting Algorithms section
3. **Configure your array** using size slider and array type buttons
4. **Adjust visualization speed** to your preference
5. **Click "Start Sorting"** to begin the visualization
6. **Use controls** to pause, step through, or reset the visualization
