# 📚 Bookmark Manager

A beautiful, responsive bookmark manager built with vanilla JavaScript that helps you organize and manage your favorite websites.

![Bookmark Manager Preview](preview.png)

## ✨ Features

### 🔍 Core Functionality
- **Add Bookmarks** - Save websites with name, URL, and category
- **Organize by Category** - News, Entertainment, Work, Education, Social, Miscellaneous
- **View by Category** - Browse bookmarks organized by category
- **Quick Search** - Search within categories
- **One-Click Visit** - Open bookmarks in new tabs

### 🛠️ Advanced Features
- **Local Storage** - Bookmarks persist between sessions
- **Export/Import** - Backup and restore your bookmarks
- **Bulk Operations** - Clear all bookmarks at once
- **Responsive Design** - Works on mobile, tablet, and desktop
- **Visual Feedback** - Toast notifications and animations
- **Keyboard Accessible** - Full keyboard navigation support
- **URL Validation** - Ensures valid URLs are saved

### 🎨 User Experience
- **Clean Interface** - Modern, minimal design with smooth transitions
- **Category Statistics** - See counts for each category
- **Quick Actions** - Import/export with single clicks
- **Error Handling** - Clear validation messages
- **Empty States** - Helpful messages when no bookmarks exist

## 🚀 How to Use

1. **Select a category** from the dropdown
2. **Add Bookmarks**:
   - Click "Add Bookmark"
   - Enter bookmark name and URL
   - Select category
   - Click "Save Bookmark"
3. **View Bookmarks**:
   - Select category
   - Click "View Category"
   - Click any bookmark to visit
4. **Manage Bookmarks**:
   - Select bookmarks with radio buttons
   - Delete selected bookmarks
   - Export/import your collection

## ⌨️ Keyboard Shortcuts

- `Enter` - Submit forms
- `Escape` - Close forms/go back
- `Tab` - Navigate between elements
- `Space` - Select checkboxes

## 💾 Data Management

- Bookmarks are stored in browser's localStorage
- Export to JSON file for backup
- Import from JSON file to restore
- No server required - works completely offline

## 🛠️ Technologies Used

- **HTML5** - Semantic markup
- **CSS3** - Flexbox, Grid, custom properties, animations
- **Vanilla JavaScript** - No frameworks or libraries
- **LocalStorage API** - Persistent data storage
- **Font Awesome** - Icons for better UX

## 📱 Browser Compatibility

Works on all modern browsers:
- Chrome 60+
- Firefox 55+
- Safari 11+
- Edge 79+
