# Sweet Delights - Shopping Cart Application

![Sweet Delights Banner](https://img.shields.io/badge/Sweet-Delights-pink)
![License](https://img.shields.io/badge/License-MIT-blue)
![Version](https://img.shields.io/badge/Version-1.0.0-green)

A full-featured e-commerce shopping cart application for a dessert shop, built with vanilla HTML, CSS, and JavaScript.

## 🌟 Features

### 🛒 Shopping Cart Functionality
- **Add/Remove Items**: Add desserts to cart or remove them with quantity controls
- **Real-time Updates**: Cart totals update immediately when items are added/removed
- **Persistent Storage**: Cart items are saved to localStorage
- **Tax Calculation**: Automatically calculates sales tax (8.25%)

### 🎨 User Interface
- **Responsive Design**: Works on mobile, tablet, and desktop
- **Modern UI**: Clean, attractive design with animations
- **Product Filtering**: Filter desserts by category (Cupcakes, Macarons, Ice Cream, Pretzels)
- **Search Functionality**: Search desserts by name or description
- **Toast Notifications**: Visual feedback for user actions

### 📱 Key Components
- Product catalog with cards
- Interactive shopping cart panel
- Category filters
- Search bar
- Checkout simulation
- Footer with contact information

## 🚀 Quick Start

### Prerequisites
- Modern web browser (Chrome, Firefox, Safari, Edge)
- Code editor (VS Code recommended)
- Live Server extension (for local development)

### Installation

1. Clone or download the project files
2. Open the project folder in your code editor
3. Install Live Server extension in VS Code (optional)
4. Open `index.html` in your browser or use Live Server
